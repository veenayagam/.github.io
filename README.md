# veenayagam.dev

Personal portfolio of **Veenayagam K Sellamuthu** — Technical Business Analyst working on enterprise systems, AI workflows, REST API specifications, and data analytics pipelines.

**Live site:** [[https://veenayagam.dev](https://veenayagam.github.io/.github.io/) *(deployed on Vercel)*

## Overview

* **Static Site Architecture:** Single `index.html` file with inline Tailwind CSS and custom glassmorphism styles.
* **Dependencies:** Powered by FontAwesome icons, Tailwind CSS CDN, and vanilla JavaScript for dynamic typewriter cursor effects and tab filtering.
* **Assets:** Images and media live in the root directory.

## Deployment

This repository is connected to Vercel. To deploy changes manually:

```bash
vercel deploy --prod
